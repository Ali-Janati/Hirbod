# هیربد — پکیج کامل (بک‌اند PHP/MariaDB + فرانت‌اند)

این نسخه، **همه‌ی تغییرات را یک‌جا** شامل می‌شود: سیستم پایه + مدیریت محصول و قیمت.
دیگر نیازی به اجرای جداگانه‌ی migration نیست — این پکیج از صفر قابل نصب است.

## ساختار فایل‌ها

```
hirbod-full/
├── api/
│   ├── login.php            ← ورود با توکن
│   ├── list_products.php    ← لیست محصولات (فعال یا همه)
│   ├── create_product.php   ← افزودن محصول (مدیر)
│   ├── update_product.php   ← ویرایش/فعال‌سازی محصول (مدیر)
│   ├── get_stock.php        ← موجودی امروز (مدیر/ناظر)
│   ├── set_stock.php        ← تنظیم موجودی (مدیر)
│   ├── submit_order.php     ← ثبت سفارش با قیمت (کاربر)
│   ├── my_orders.php        ← سفارشات کاربر جاری
│   ├── all_orders.php       ← همه سفارشات (مدیر/ناظر)
│   ├── save_forecast.php    ← ذخیره پیش‌بینی (مدیر)
│   └── get_forecast.php     ← دریافت پیش‌بینی (مدیر/ناظر)
├── config/
│   └── db.php                ← اتصال دیتابیس + همه توابع کمکی (شامل محصولات)
├── sql/
│   └── schema.sql             ← اسکیمای کامل (users, products, stock, forecast, orders)
├── index.html                 ← فرانت‌اند کامل (با مدیریت محصول و قیمت)
└── README.md                  ← همین فایل
```

> ⚠️ این پکیج شامل مدیریت **توکن‌ها** (`list_tokens.php` / `create_token.php`) نیست، چون این دو فایل را
> خودتان یا نسخه‌ی دیگری اضافه کرده بودید و من محتوای اصلی آن‌ها را در اختیار ندارم.
> اگر آن دو فایل را هم داشتید، همان‌ها را کنار این فایل‌ها در پوشه `api/` بگذارید — بقیه سیستم با آن‌ها سازگار است.
> در غیر این صورت کارت «مدیریت توکن‌ها» در پنل مدیر خطا می‌دهد (چون آن دو endpoint پیدا نمی‌شوند)؛
> بگویید تا آن دو فایل را هم از نو برایتان بسازم.

## نصب روی XAMPP (ویندوز) — از صفر

### ۱. کپی فایل‌ها
پوشه `hirbod-full` را کامل کپی کنید و اسمش را به `hirbod` تغییر دهید، بعد بگذارید توی:
```
C:\xampp\htdocs\hirbod\
```

### ۲. ساخت دیتابیس
1. Apache و MySQL را در XAMPP Control Panel روشن کنید.
2. بروید به `http://localhost/phpmyadmin`
3. تب Import را بزنید → فایل `sql/schema.sql` را انتخاب کنید → Go

### ۳. تنظیم `config/db.php`
```php
define('DB_HOST', 'localhost');
define('DB_NAME', 'hirbad_db');
define('DB_USER', 'root');
define('DB_PASS', '');   // در XAMPP پیش‌فرض خالی است
```

### ۴. تنظیم آدرس API در `index.html`
خط زیر را پیدا کنید و آدرس را با محیط خودتان جایگزین کنید:
```javascript
const API_BASE = 'http://localhost/hirbod/api';
```

### ۵. تنظیم توکن‌های واقعی
توکن‌های نمونه در `schema.sql` فقط برای تست هستند. در phpMyAdmin جدول `users` را باز کنید و مقادیر
`token` را با مقادیر امن (مثلاً خروجی `openssl rand -hex 16`) جایگزین کنید.

### ۶. تست
```
http://localhost/hirbod/index.html
```

## تنظیم قیمت محصولات

بعد از نصب، محصولات پایه (صورتی/آبی/سفید/دریایی) با قیمت **۰ تومان** وارد می‌شوند.
با توکن مدیر وارد شوید، در کارت «🧂 محصولات و قیمت» قیمت واقعی هرکدام را تنظیم کنید،
یا محصول جدید اضافه کنید.

## نکات فنی مهم

- همه خروجی‌های API به فرمت `{ success: bool, message: string, data: ... }` هستند.
- `submit_order.php` هنگام ثبت سفارش، قیمت لحظه سفارش را در ستون‌های `unit_price` و `total_price`
  ذخیره می‌کند — یعنی تغییر بعدی قیمت روی سفارش‌های قبلی اثر نمی‌گذارد.
- موجودی با تراکنش دیتابیس (`FOR UPDATE`) کسر می‌شود تا در سفارش‌های همزمان مشکلی پیش نیاید.
- مشتریان عادی به موجودی دسترسی ندارند؛ فقط مدیر و ناظر می‌بینند.
- لیست محصولات، موجودی و پیش‌بینی همگی **داینامیک** از جدول `products` خوانده می‌شوند —
  محصول جدید که اضافه کنید، بدون تغییر کد در همه‌ی بخش‌ها ظاهر می‌شود.
